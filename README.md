# Avaliação de documentos

Avaliação teórica responsiva com 8 questões objetivas justificadas e 4 discursivas. Sem atividades práticas ou upload de imagens.

Base temática: editor de texto, regras de formatação do material da aula, interpretação de trabalho sobre crimes virtuais e folders.

O aluno informa nome, turma e data, responde e baixa o PDF para entrega ao professor. O progresso fica no navegador; há backup e restauração em JSON. Não há envio automático de respostas, correção automática ou vigilância.

## Acesso

GitHub Pages: https://ianakiles.github.io/avaliacao-documentos/

Versões: acrescente `?versao=A` ou `?versao=B`. Uma tentativa salva mantém sua versão.

## Hospedagem

Site estático, sem instalação. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

## Privacidade

Não publique respostas dos alunos, gabarito ou anexos com dados pessoais. Este repositório contém apenas a aplicação. Pesquisas adicionais são orientadas a blogs permitidos; isso não bloqueia navegação externa nem uso de IA.

As regras de ABNT são apresentadas como orientações do material da aula, sem alegação de revisão normativa atualizada.
